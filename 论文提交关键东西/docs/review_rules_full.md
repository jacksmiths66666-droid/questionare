# TISP 数据清洗 — 筛选与审核规则（全流程）

> 覆盖：信号筛选（行为信号分层 + 一票否决）→ 分层审核（HIGH / VERIFY / MEDIUM / 非队列）→ 最终汇总

---

## 〇、信号筛选（程序计算）

信号筛选分两条**独立通道**，互不影响：

**通道一：行为信号 → 分层**（决定是否进入复核队列）

对每行计算 4 个行为信号，统计 signal_count = 0 / 1 / 2+：

| 信号 | 规则 | 依据 |
|:----:|------|------|
| A 长字符串 | 任一答案连续相同字符 ≥ 13 | 疑似 straightlining（乱敲/重复字符），答案无内容区分度 |
| B 奇偶过低 | 奇偶字符分布显著偏离随机 | 乱打键盘时奇偶比例失衡 |
| C 异常值 | Mahalanobis 距离超出阈值 | 多维特征（长度、字符分布等）综合偏离群体 |
| 注意力题 | 注意力题答错 | 未认真作答的直接证据 |

分层结果：
- signal_count = 0 → NORMAL（54,913 行，含 IDN/PRT 之外的正常行）
- signal_count = 1 → MEDIUM（16,673 行）
- signal_count ≥ 2 → HIGH（160 行）
- IDN/PRT 且注意力题答错 → VERIFY（176 行，不计入 signal_count）

其中 HIGH / VERIFY / MEDIUM 共 **17,009 行**进入复核队列。

**通道二：一票否决（乱码/全空）→ 直接判 invalid**

开放题纯乱码（重复字符 / 纯符号 / 纯数字 / 编码错误）或全量表缺失 → **直接判 invalid**，不进复核队列、不参与分层、不计入 signal_count。

**一票否决分两处识别，合计 77 行：**

| 识别阶段 | 行数 | 说明 |
|:--------|:----:|:-----|
| 信号筛选（通道二） | 45 | 长乱码（重复/符号/数字/编码错误，字符数较多，可被规则直接识别） |
| 最终生成（补充检测） | 32 | 短乱码（如 `Jjjj`、`xxx` 等 4~15 字符乱敲，信号筛选阶段未触发规则） |
| **合计** | **77** | 全部位于非复核队列行中，直接判 invalid |

## 一、HIGH 层（signal_count ≥ 2）

### 定义
触发 ≥2 个独立行为信号（longstring、mahalanobis、odd_even、attention）
→ 数据质量高度可疑，需综合判定

### 判定标准：双链框架

| 证据链 | 维度 | 考察内容 |
|--------|------|---------|
| **A：开放题文字质量** | 是否作答 | 排除 NA / -99 / 空白 |
| | 文字长度 | 字符数反映认知投入 |
| | 语言有效性 | 元音比例 + 字符多样性（排除乱码） |
| | 语义合理性 | 专业名词/完整短语 vs 单字敷衍 |
| **B：信号叠加** | 信号组合 | ≥2 个独立信号同时触发 |
| | 信号独立性 | 异常行为覆盖不同维度 |

### 判定规则

| 判定 | 条件 |
|:----:|------|
| **valid** | A 充足（至少一题有 ≥8 字符的实质内容）→ 推翻 B 的怀疑 |
| **invalid** | A 不足（两题空 / 字符极少 / 乱码 / 无意义单词）→ B 起主导 |

### invalid 典型情形
- 两题都空（-99 / NA）
- 单题极短（≤7 字符）且另一题空：如 `B='' T='Sida'`、`B='alle' T=''`
- 含乱码：如 `B='<<<<'`、`B='.'`、`T='òkljlklk'`
- 无意义单词：如 `B='Kami'`（仅"我们"，无上下文）

### valid 边界示例（最短通过行）
| id | 内容 | 字符 | 理由 |
|:--:|------|:---:|------|
| 11575 | T='Einstein' | 8 | 专有名词，有内涵 |
| 18935 | B='Iedereen' | 8 | "每个人"，回答了"谁受益" |
| 54574 | T='research' | 8 | 回答了"什么让科学家可信" |
| 37772 | T='Pravdivosť' | 10 | "诚实"，回答了可信标准 |
| 39592 | T='im confused' | 11 | 表达了观点 |

### 结果：160 行 → 134 valid + 26 invalid（valid 率 83.8%）

## 二、VERIFY 层（IDN/PRT + attention check fail）

### 定义
- 国家为 IDN 或 PRT
- 注意力题答错（`ATTCHECK_NUMBER ≠ 213` 或 `ATTCHECK_RES ≠ 1`）
- 但因 IDN/PRT 降级，**不计入 signal_count**（signal_count = 0）
- → 行为上无异常信号，仅因国家被标记而需复查

### 判定标准：内容判断

核心原则：**写了真实语言且在回答问题 = valid**，不因长度短或措辞简略而判 invalid。

| 判定 | 条件 |
|:----:|------|
| **valid** | 至少一题写了与问题相关的真实语言 |
| **invalid** | 仅限以下 7 行模式的明确非回答 |

**注意：** `Não`（葡萄牙语"不/没人"）不被视为泛词，因为其可构成合法回答（"没人受益"）。

### invalid 唯一清单（7 行）

| 模式 | BENEFIT | TRUST | 理由 |
|:----:|:--------|:------|:-----|
| 单字母 | (空) | N | 非词语 |
| 单字母 | (空) | Y | 非词语 |
| 随意回复 | (空) | Ok | 非回答 |
| 键盘乱敲 | jh | kjg | 非语言 |
| 泛词 | ada | (空) | "有"不构成回答 |
| 泛词 | (空) | dapat | "能/获得"不构成回答 |
| 泛词 | (空) | Bisa | "可以"不构成回答 |

### 未被判 invalid 的短内容示例（valid）

| BENEFIT | TRUST | 判定理由 |
|:--------|:------|:---------|
| Negara | (空) | 回答了"国家受益" |
| Masyarakat | (空) | 回答了"社会受益" |
| Kita semua | (空) | 回答了"我们所有人受益" |
| (空) | Kepandaiannya | 回答了"智慧/能力" |
| Não | Honestidade | 两题都有意思（"没人"+"诚实"） |
| a medicina | não sei | B 答"医学"，T 答"不知道"（有效表达观点） |

### 结果：176 行 → 169 valid + 7 invalid（valid 率 96.0%）

## 三、MEDIUM 层（signal_count = 1）

### 定义
恰好触发 1 个行为信号。95% 为 longstring（矩阵题刷同一选项 / straightlining），其余为 odd_even / mahalanobis / attention。

### 判定标准：按信号类型分两种处理

#### 3.1 longstring 行（15,856 行）→ 全部 invalid

**理由：** 命中信号 A（连续相同字符 ≥ 13）即 straightlining 的直接证据——正常作答不可能出现 13+ 个连续相同字符，此类文本为重复/乱敲字符，**不构成真实语言内容，无法通过双链框架的实质要求**（双链验证依赖"真实作答文本 ≥30 字符"，对重复字符文本不适用），属系统性作答失效，无需逐行内容判断。

#### 3.2 非 longstring 行（817 行：OE 511 + MD 303 + AT 3）→ 内容审核

**理由：** odd_even / mahalanobis / attention 信号不像 longstring 那么致命（可能只是答题过快或数值异常），需用开放题内容交叉验证。

内容审核规则（与 VERIFY 相同框架）：

| 判定 | 条件 |
|:----:|------|
| **valid** | 至少一题写了真实语言且在回答问题（含中文、日文、韩文、西里尔文、阿拉伯文等非拉丁文字） |
| **invalid** | 两题都空 / 单字母 / 键盘乱敲 / 纯符号 / 纯数字 / 泛词 |

invalid 典型情形：

| 内容 | 理由 |
|:----:|:-----|
| 两题都空 | 无作答（79 行） |
| Vjkkk / Gffhh / Sjxb | 键盘乱敲 |
| -- / ... | 纯符号 |
| 0 / 100% | 纯数字 |
| има / ne | 泛词（不构成回答） |

未被判 invalid 的短内容示例：

| 内容 | 判定理由 |
|:----:|:---------|
| 事实 / 科学家 / 市民 | 中文实义词，回答了问题 |
| Щастие / Ученые / ничего | 西里尔文实义词 |
| ممياز | 阿拉伯文"卓越"，回答了问题 |
| 관심없음 / 그냥 | 韩文，表达了观点 |
| nvt | 荷兰语"不适用"，标准应答 |

### 结果

| 信号 | 行数 | 判定 |
|:----:|:----:|:-----|
| longstring | 15,856 | invalid |
| OE / MD / AT | 817 | 729 valid + 88 invalid |
| **MEDIUM 合计** | **16,673** | **729 valid + 15,944 invalid** |

## 四、非复核队列行（54,913 行）

未进入复核队列的行默认无行为异常特征，按乱码检测判定：
- 77 行命中一票否决（信号筛选阶段 45 行长乱码 + 最终生成阶段 32 行短乱码补充检测）→ 直接判 invalid
- 其余 54,836 行 → 直接判 valid

## 五、三层的本质区别

| 维度 | HIGH | VERIFY | MEDIUM |
|:----|:----|:-------|:-------|
| 入选理由 | signal_count ≥ 2 | IDN/PRT + attention fail | signal_count = 1 |
| 行为证据强度 | 强（多重信号叠加） | 弱（attention fail 不计入信号） | 中（单一信号） |
| 审核严度 | 严（≥8 字符实质内容） | 宽（语义正确即可） | longstring 直接淘汰；非 longstring 内容审核 |
| invalid 率 | 16.3%（26/160） | 4.0%（7/176） | 95.6%（15,944/16,673） |
| 逻辑 | 多重异常 → 需强证据自证 | 行为正常 → 从宽 | 单信号 → longstring 一刀切，其他交叉验证 |
