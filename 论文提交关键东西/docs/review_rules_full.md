# D087 数据清洗 — 筛选与审核规则（全流程）

> 覆盖：信号筛选（双通道：行为信号分层 + 跳题违规一票否决）→ 分层人工复核（HIGH / MEDIUM / NORMAL / VETO）→ 最终汇总。
> 数据集：PROTEiCA project survey（西班牙，2019），N = 2,159（CATI 1,856 / CAWI 294 / CAWI-CATI 9）。
> 本文档为论文方法论核心；数字均为实际运行输出（2026-08-02 定稿）。

---

## 〇、关键术语（先读这里）

| 术语 | 定义 |
|------|------|
| **DUR** | 访谈时长（分钟），数据自带的 `DUR` 列。CATI 为访问员系统记录，CAWI 为自答系统记录 |
| **DUR_z** | 时长标准分：`ln(DUR)` 在**各调查模式组内**（CATI / CAWI 分别）标准化，`(lnDUR − 组均值) / 组标准差`。DUR_z < 0 = 快于组内平均；约 −1.0 ≈ 快于 84% 的受访者，−1.5 ≈ 快于 93% |
| **CI（Concern Index）** | 单行命中的信号规则数，0–5 |
| **有效文本** | 开放题字段的实质内容判定（见 §一.1） |
| **自证（substantiation）** | 开放题中出现能定位**具体议题 + 立场**的实质内容，证明受访者真实投入 |
| **泛词** | 无法定位具体议题/立场的开放题内容：裸词（IGUALDAD、TODAS）、编码值（88/99/0）、仅媒体来源（电台/电视台名）、DK/NA 拒答、关系词（"家人说"） |
| **信号命中** | 满足某条信号规则的阈值条件，见 §〇.1 表 |

## 〇.1 信号筛选（程序计算：`脚本/01_screen.py`）

信号筛选分两条**独立通道**，互不影响：

**通道二先于通道一执行：一票否决（跳题违规）→ 直接判 invalid**

问卷跳题逻辑硬性约束（独立于行为质量的客观违规）：
- **R1**：P12 = "No"（回答未参加 3/8 妇女节游行）但 P12Btx（游行参与形式开放题）却填了内容 → 3 行
- **R2**：P27 ≠ "Yes"（回答无同住伴侣）但 P27C（伴侣性别）却选了 Man/Woman → 37 行
- 合计 **40 行 → 直接判 invalid**，不进复核队列、不参与分层、不计入 signal_count（`veto_any = 1`）

**通道一：行为信号 → 分层**（决定是否进入复核队列）

对每行计算 **5 条独立信号规则**（仅非跳题样本 2,119 人；阈值由 2,119 人数据分布定标，见清洗报告"规则收紧记录"）：

| 信号规则 | 规则 | 命中 | 依据 |
|:--------:|------|:----:|------|
| DUR 短侧 | DUR < 分模式 P10（CATI 8.5 / CAWI 6.8 min） | 199 | 快答/敷衍：时长显著低于正常作答 |
| DUR 长侧 | DUR > 全体 P99（27.6 min） | 21 | 中断/闲聊/异常停留（非致命，倾向复核） |
| MD | P11A–E 五题（P11A 为反向题，先 6−v 翻转）Mahalanobis D² > P95 = 11.6 | 97 | 多维态度作答模式偏离群体（详见下方说明） |
| Longstring | 21 道序数题归一化后最长连续相同 ≥ 6 且有效题 ≥ 11 | 210 | straightlining：连续同选 |
| DK/NA | 55 道核心题拒答数 ≥ 4 | 119 | 敷衍/能力不足：大量不知道/不回答 |

**实现细节（保证可复现）**：
- **MD**：P11A–E 是 1–5 点 Likert 量表（P11A 措辞方向与其他四题相反，故翻转）；对全部完整作答行计算 5 题协方差矩阵的 Mahalanobis D²。D² 大 = 该行作答模式偏离群体中心（例如盲目全选"同意"或"不同意"）；任一行有缺失则不参与 D² 计算（MD_d2 记缺失）。
- **Longstring**：21 题**混合 4 点（10 题）与 5 点（11 题）量表**，先将各题得分除以各自最大值归一化到 [0,1]，再按相邻比较统计最长连续相同（避免 4/5 点量表因选项密度不同被误判）；有效题 ≥ 11（过半）才计算；LS 题单见附录 B。
- **DK/NA**：拒答取值集合为 DK/NA/NC/NS/Can't say/Can't remember/No memories/无社交网络类/空字符串（见附录 C），在 55 道核心题（附录 A）中计数；≥4 题 = 55 题的 7.3%。
- **双通道 9 行**（CAWI-CATI 模式）：DUR 短侧定标归入 CAWI 组计算。
- 信号独立计算互不冲突；一行可同时命中多条 → **CI = 命中条数（0–5）**。

| 分层 | CI | 数量 | 去向 |
|:----:|:--:|:----:|:----:|
| NORMAL | 0 | 1,527 | 直接 valid（不进入复核） |
| MEDIUM | 1 | 538 | 进入复核队列（常规层） |
| HIGH | ≥2 | 54 | 进入复核队列（高优先级） |
| VETO | —（跳题） | 40 | 直接 invalid |

复核队列合计 **592 行**。输出：`data/signals.csv`（全量 2,159 行 + 信号标记列）。

## 一、人工复核评分体系（HIGH / MEDIUM 统一适用）

复核队列 592 行统一走同一套**三维度评分 + 门槛**（HIGH 与 MEDIUM 的唯一区别：C 维度高优先级档更严，见 §一.3）。

### 一.1 维度 A：开放题投入度（0–2）

**4 道开放题**：P07Ctx（信息/媒体来源）、P10tx（议题与理由）、P12Btx（游行参与形式）、P16Btx（其他说明）。逐字段判定"有效文本"：

> **有效文本判定（全部满足才算有效）**：
> 1. 去除首尾空白后 ≥ 2 个字符
> 2. 至少包含一个字母（含西语字母 áéíóúñü 等）
> 3. 不是纯编码值（88 / 99 / 0 / -999 等数字串）
> 4. 不是 DK/NA 类拒答（DK、Can't say 等）

| 得分 | 条件 | 例 |
|:--:|------|----|
| **0** | 有效字段 ≥ 2 个 | 两个开放题均有实质内容 |
| **1** | 有效字段恰好 1 个，且该字段含**实质议题内容**（具体议题词：工资/暴力/虐待/权利/歧视等，如 SALARIAL、VIOLENCIA、DERECHOS；或具体立场表述），即非泛词 | 唯一字段 P10 = "VIOLENCIA DE GENERO" |
| **2** | 有效字段 = 0 个；或唯一有效字段为**泛词**（裸词 IGUALDAD/TODAS、编码 88/99/0、仅媒体来源如电台名、DK/NA 拒答） | 唯一字段 = "COPE"（电台名） |

> 实际定稿中 A=1 共 122 行，其中唯一有效字段为 P10tx 者 119 行、P07Ctx（媒体来源+具体议题）者 3 行。

### 一.2 维度 B：作答形态（0–2）

以 P11A–E 五题作答标签多样性评估（P11A 为反向题，评分时用翻转值口径）：

| 得分 | 条件 |
|:--:|------|
| **0** | P11 五题有效值 ≥ 2 种（态度有区分）；或全同但开放题有实质自证 |
| **1** | 单值（五题全选同一档）或部分缺失 |
| **2** | 全同连击且自证不足（LS 连击从严，结合人工表 B_DICT 复核） |

### 一.3 维度 C：过程背景（0–2）

| 得分 | 条件 |
|:--:|------|
| **0** | DUR_z > −1.0（时长正常或轻微偏快） |
| **1** | 常规层（MEDIUM）：DUR_z ≤ −1.5；或 −1.5 < DUR_z ≤ −1.0 且开放题无自证 |
| **2** | 高优先级（HIGH）：DUR_z ≤ −1.0；或访问员标记率异常 |

- **DUR_z**：见术语表——分模式**对数**标准化（时长分布右偏，取 ln 后更接近正态）。
- **访问员标记率**：某访问员（CODINT）名下样本中进入复核池的比例 ÷ 全样本复核池比例（即"标记率超均值倍数"，包内 `analysis/复核明细.csv` 提供该列）。>1 表示该访问员名下异常样本偏多（可能诱导快答/代答）。
- **如实说明**：C = 2 在实际定稿中共触发 **10 行，全部为 HIGH 层 DUR_z ≤ −1.0**（全部剔除）；"访问员标记率异常"条目为设计保留项，本次数据中无单因标记率触发 C=2 的样本（最高 1.44 倍均值）。

### 一.4 决策机制（门槛优先，总分兜底）

```
总分 = A + B + C（0–6）

第一步（门槛）：维度 A ≥ 2（0 个或仅泛词字段）→ 无条件剔除（363 行）
第二步（总分）：其余 A ≤ 1 样本，总分 0–2 → 保留；3–6 → 剔除（224 / 5 行）
```

> 注意"2 分"两向：剔除的 2 分 = 门槛样本（A=2,B=0,C=0）；保留的 2 分 = 门槛外（A=0/1,B+C 合计 2）。
> 依据：复核池样本本就携带机械信号，信号 + 完全无自证材料时信号起主导——与 TISP 方案 HIGH 层"A 不足 → 怀疑起主导"同构；同时解决阶段 1 定标后的效率校准问题（详见清洗报告 §4）。

## 二、HIGH 层（CI ≥ 2，54 行）——高优先级

多信号叠加（覆盖不同维度）→ 数据质量高度可疑。**走同一评分体系**，但 C 维度采用高优先级档（DUR_z ≤ −1.0 即得 2 分，门槛更严）。

### 结果：54 行 → 23 valid + 31 invalid（valid 率 42.6%）

| 得分档 | HIGH valid（23） | HIGH invalid（31） |
|:------:|:--:|:--:|
| A 分布 | A0 = 13 + A1 = 10 | A2 = 27（门槛）+ A1 = 4（总分 3–6） |
| 总分分布 | — | 2 分 14 / 3 分 9 / 4 分 7 / 5 分 1 |

### invalid 典型情形
- 4 个开放字段全部为空 / 编码值（88 / 99 / 0）/ DK 拒答
- 唯一有效字段为**泛词/媒体来源**（COPE 电台名、IGUALDAD 裸词、88）→ A=2 门槛剔除
- 快答（DUR 短侧）+ 开放题零投入

### 真实示例（均为定稿记录）

## 六、三层差异与最终汇总

| 维度 | HIGH | MEDIUM | NORMAL |
|:----|:----|:-------|:-------|
| 入选理由 | CI ≥ 2（多信号叠加） | CI = 1（单一信号） | CI = 0 |
| 行为证据强度 | 强（信号叠加，覆盖不同维度） | 中（单一维度） | 无 |
| 复核严度 | 同一评分体系 + C 维度高优档（DUR_z ≤ −1.0 → C=2） | 标准档（DUR_z ≤ −1.5 或 −1.5~−1.0 无自证 → C=1） | 直接 valid |
| invalid 率 | 57.4%（31/54） | 62.6%（337/538） | 0% |
| 逻辑 | 多重异常 → 需强证据自证 | 单信号 → 无自证则信号主导 | 无异常 → 信任 |
