## 5. 人工复核（阶段 2）

- **复核队列**：592 = HIGH 54 + MEDIUM 538
- **评分体系**（两档统一）：维度 A 开放题投入度（0–2）/ B 作答形态（0–2）/ C 过程背景（0–2），总分 0–6
- **决策机制**：门槛优先（A≥2 → 无条件剔除）→ 总分兜底（门槛外 0–2 保留 / 3–6 剔除）
- **结果**：HIGH 23 valid + 31 invalid；MEDIUM 201 valid + 337 invalid；合计 224 valid + 368 invalid
  - 门槛剔除 363（A=2）；门槛外按总分剔除 5（A=1 且总分 3–6）
  - MEDIUM 保留总分：0 分 92 / 1 分 105 / 2 分 4；剔除总分：2 分 253（门槛）/ 3 分 45 / 4 分 36 / 5 分 3
- 决策依据逐条留存包内 `analysis/复核明细.csv`（592 行，含 33086 追溯记录）
