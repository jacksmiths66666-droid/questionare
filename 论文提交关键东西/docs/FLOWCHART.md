# TISP 数据清洗全流程（流程图）

> 阶段 → 动作 → 产出文件（与交付包一一对应，★ = 交付文件）

```
┌─ 阶段 1｜信号筛选（运行：python 脚本/01_screen.py）──────────────────────────┐
│  输入：原始数据dataset.csv（71,922 × 126）                                  │
│  通道一：行为信号（A 长字符串 / B 奇偶 / C Mahalanobis / 注意力题）→ 分层      │
│     0 信号 → NORMAL 54,913  │  1 信号 → MEDIUM 16,673                        │
│     ≥2 信号 → HIGH 160     │  IDN/PRT → VERIFY 176                          │
│  通道二：一票否决（长乱码/全空）→ 直接判 invalid（45 行，不进复核队列）        │
│  产出：outputs/signals.csv（全量信号标记 71,922 行）★预置                     │
│        └ 复核队列初版（HIGH + VERIFY + MEDIUM = 17,009 行）                  │
│  文档：docs/review_rules_full.md 第〇节（信号定义与分层）                     │
└──────────────────────────────────────────────────────────────────────────┘
                                          ↓ 17,009 行进入复核
┌─ 阶段 2｜分层内容审核（按判定标准逐条执行，无脚本）───────────────────────────┐
│  输入：复核队列 17,009 行                                                    │
│  动作：HIGH 双链框架 / VERIFY 内容判断 / MEDIUM 分层                          │
│       （longstring 15,856 行一刀切无效，其余 817 行内容审核）                 │
│  产出：data/review_queue.csv（终版，decision + reason）★交付                 │
│  文档：docs/review_rules_full.md 一~三章（判定标准与典型示例）                │
└──────────────────────────────────────────────────────────────────────────┘
                                          ↓
┌─ 阶段 3｜最终数据集生成（运行：python 脚本/02_build_final.py）────────────────┐
│  输入：outputs/signals.csv + data/review_queue.csv                           │
│  队列行 17,009 → 直接采用复核结论（decision）                                │
│  非队列行 54,913 → 乱码检测：                                               │
│      45 行长乱码（通道二已判） + 32 行短乱码（本阶段补充识别）= 77 行 → invalid│
│      其余 54,836 行 → valid                                                  │
│  产出：data/final_all.csv（71,922 × 155 列，final_decision + _source）★交付  │
│        data/summary.csv（55,868 / 16,054 / 77.68%）★交付                    │
│  文档：docs/review_rules_full.md 四~六章                                    │
└──────────────────────────────────────────────────────────────────────────┘
                                          ↓
┌─ 阶段 4｜彩色核查版（运行：python 脚本/03_build_xlsx.py）─────────────────────┐
│  输入：final_all.csv（阶段 3 的产物）                                        │
│  动作：4 键条件着色（判定绿/红、来源蓝/灰/黄、分层、信号数）+ 冻结首行 + 筛选  │
│  产出：data/final_all.xlsx（46.7 MB）★交付                                  │
└──────────────────────────────────────────────────────────────────────────┘
                                          ↓
┌─ 阶段 5｜文档整理───────────────────────────────────────────────────────────┐
│  产出：README.md（交付说明）★交付                                            │
│        docs/review_rules_full.md（规则全流程）★交付                          │
│        docs/DATA_CLEANING_REPORT.md（清洗报告）★交付                         │
│        本文件（流程图）★交付                                                │
└──────────────────────────────────────────────────────────────────────────┘
```

## 关键数字（77 行的两阶段识别）

| 识别阶段 | 行数 | 说明 |
|:--------|:----:|:-----|
| 信号筛选（通道二一票否决） | 45 | 长乱码（重复/纯符号/纯数字/编码错误） |
| 最终生成（02 补充检测） | 32 | 短乱码（`Jjjj`、`xxx` 等 4~15 字符） |
| **合计** | **77** | 全部位于非复核队列中，直接判 invalid |
