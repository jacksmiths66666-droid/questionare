# D087 数据清洗流程（FLOWCHART）

> 全流程视图：每个阶段 = **动作 + 所用规则 + 产出文件（论文提交关键东西 包内路径）**。
> 数据：PROTEiCA survey（西班牙，2019）｜N = 2,159 ｜ 定稿 2026-08-02。

## 一、主流程图

```
═══════════════════════════════════════════════════════════════════════════
 阶段 0 · 接收原始数据
═══════════════════════════════════════════════════════════════════════════
  动作   收录官方数据（英语版为主分析版本），核对样本量与字段
  规则   无（原始接收，不做任何处理）
  ─── 产出：原始数据dataset.csv（2,159 行 × 103 列：P1–P28 及子题、
      4 开放文本字段 P07Ctx/P10tx/P12Btx/P16Btx、DUR、MODE、CODINT、权重）
        │
        ▼
═══════════════════════════════════════════════════════════════════════════
 阶段 1 · 信号筛选（程序：脚本/01_screen.py）
═══════════════════════════════════════════════════════════════════════════
  通道二 · 跳题一票否决（分类规则：R1/R2 硬性跳题约束）
  ├─ R1: P12=No 但 P12Btx 有内容 ........... 3 行 → VETO
  ├─ R2: P27≠Yes 但 P27C 有性别 ........... 37 行 → VETO
  └─ VETO 40 行 → 直接 invalid ✗（不进复核、不计信号）
                        │
  通道一 · 行为信号（分类规则：5 条阈值规则，仅 2,119 行）
  ├─ DUR 短侧  < 分模式 P10（CATI 8.5 / CAWI 6.8 min）... 199
  ├─ DUR 长侧  > 全体 P99（27.6 min）............... 21
  ├─ MD       Mahalanobis D² > P95（11.6，P11A–E 翻转） 97
  ├─ LS       21 题归一化连续同选 ≥ 6（有效 ≥ 11）.... 210
  └─ DK/NA    55 核心题拒答 ≥ 4 .................... 119
                        │
  分层规则：CI = 命中信号数（0–5）
  ├── CI = 0 → NORMAL  1,527 → 直接 valid ✔（规则：无信号即无异常证据，基线信任）
  ├── CI = 1 → MEDIUM    538 ─┐
  └── CI ≥ 2 → HIGH        54 ─┤（进入阶段 2 复核）
                                ▼
  ─── 产出：data/signals.csv（2,159 行：row_id / veto_any / screening_tier /
      signal_count / trigger_reason / CI / 5 个 flag / DUR / MD_d2 / LS_run /
      DKNA_count + 全部原始列）
═══════════════════════════════════════════════════════════════════════════
 阶段 2 · 人工复核（队列 592 = 54 HIGH + 538 MEDIUM，同一评分体系）
═══════════════════════════════════════════════════════════════════════════
  评分规则：三维度 0–2（HIGH 与 MEDIUM 统一；C 维度高优档更严）
  A 开放题投入度（分类规则：有效文本判定——≥2 字符/含字母/非编码/非 DK/NA）
    ├─ 有效字段 ≥ 2 → 0 ｜ 有效 1 且实质议题内容 → 1 ｜ 0 个或仅泛词 → 2
  B 作答形态（分类规则：P11A–E 翻转值多样性 + LS 连击从严）
    ├─ ≥2 种有效值（或全同但自证）→ 0 ｜ 单值/部分缺失 → 1 ｜ 连击无自证 → 2
  C 过程背景（分类规则：DUR_z 分模式对数标准化 + 访问员标记率）
    ├─ DUR_z > −1.0 → 0 ｜ 常规层 ≤ −1.5 或中快无自证 → 1 ｜ 高优 ≤ −1.0 / 标记率异常 → 2
        │
  决策规则（门槛优先，总分兜底）
  ├─ 门槛：A ≥ 2 → 无条件剔除 ................... 363（MEDIUM 336 + HIGH 27）
  └─ 门槛外：A ≤ 1 → 总分 0–2 → 保留 224 ｜ 总分 3–6 → 剔除 5
        │
  信度复评（规则：分层随机 20% = 119 条，种子 20260802；κ ≥ 0.70 达标）
  决策一致 119/119 · Cohen's κ = 1.000 · 3 类差异闭环（8 证据 / 14 B 口径 / 1 规则演进）
  ─── 产出：analysis/复核明细.csv（592 行：三维度分/总分/决策/备注 + 全部证据列）
  ─── 产出：analysis/信度报告.md + analysis/信度检验_抽样119.csv + analysis/信度证据v3.txt
                        ▼
═══════════════════════════════════════════════════════════════════════════
 阶段 3 · 最终汇总（程序：脚本/02_build_final.py）
═══════════════════════════════════════════════════════════════════════════
  判定规则（确定性映射 + 断言）
  ├─ 队列行 592    → 用 analysis/复核明细.csv 的 决策 列（保留→valid / 剔除→invalid）
  ├─ 非队列 1,567  → NORMAL 直接 valid ｜ VETO 直接 invalid
  └─ 断言：valid = 1,751 且 invalid = 408，否则中止
  ┌──────────────┬────────┬─────────┬─────────┐
  │      层      │  行数  │  valid  │ invalid │
  ├──────────────┼────────┼─────────┼─────────┤
  │ NORMAL       │ 1,527  │ 1,527   │    0    │
  │ HIGH         │    54  │    23   │   31    │
  │ MEDIUM       │   538  │   201   │  337    │
  │ VETO         │    40  │     0   │   40    │
  ├──────────────┼────────┼─────────┼─────────┤
  │ 合计         │ 2,159  │ 1,751   │  408    │
  │ 占比         │  100%  │ 81.1%   │ 18.9%   │
  └──────────────┴────────┴─────────┴─────────┘
  ─── 产出：data/final_all.csv（2,159 行 × 119 列：final_decision / _source /
      screening_tier / signal_count / trigger_reason + 全部信号与原始列）
                        ▼
═══════════════════════════════════════════════════════════════════════════
 阶段 4 · 彩色核查版（程序：脚本/03_build_xlsx.py）
═══════════════════════════════════════════════════════════════════════════
  着色规则（条件格式，便于人工核查）
  ├─ final_decision  → valid 绿 / invalid 红
  ├─ _source         → queue 蓝 / nonsignal 灰 / veto 黄
  ├─ screening_tier  → HIGH 橙 / MEDIUM 黄 / NORMAL 灰 / VETO 紫
  └─ signal_count    → 2 橙 / 1 黄 / 0 灰
  ─── 产出：data/final_all.xlsx（2,159 行，冻结首行 + 自动筛选）
```

## 二、阶段 → 规则 → 产出对照表

| 阶段 | 动作（何时干什么） | 所用分类规则 | 产出文件（包内路径） |
|:----:|-------------------|--------------|----------------------|
| 0 | 接收原始数据 | 无（原样收录） | `原始数据dataset.csv` |
| 1 | 信号筛选（01_screen.py） | 通道二：R1/R2 跳题一票否决（40 行 VETO）；通道一：DUR 短侧 <P10（CATI 8.5/CAWI 6.8）、DUR 长侧 >P99（27.6）、MD D²>P95（11.6）、LS 连续 ≥6 且有效 ≥11、DK/NA ≥4；分层：CI 0→NORMAL / 1→MEDIUM / ≥2→HIGH | `data/signals.csv` |
| 2 | 人工复核（评分 + 信度复评） | 三维度评分：A 开放题投入度（有效 ≥2→0 / 1 实质→1 / 0 或泛词→2）、B 作答形态（多样→0 / 单值→1 / 连击→2）、C 过程背景（DUR_z>−1→0 / ≤−1.5 或中快无自证→1 / 高优 ≤−1.0→2）；决策：门槛 A≥2 无条件剔（363）、门槛外总分 0–2 保留（224）/ 3–6 剔除（5）；信度：分层随机 20% 抽样 119，κ ≥ 0.70 | `analysis/复核明细.csv`、`analysis/信度报告.md`、`analysis/信度检验_抽样119.csv`、`analysis/信度证据v3.txt` |
| 3 | 最终汇总（02_build_final.py） | 队列行用复核明细的 决策 列；NORMAL 直接 valid / VETO 直接 invalid；断言 1,751/408 | `data/final_all.csv` |
| 4 | 彩色核查版（03_build_xlsx.py） | 条件着色：final_decision 绿/红、_source 蓝/灰/黄、tier 橙/黄/灰/紫、signal_count 橙/黄/灰 | `data/final_all.xlsx` |

> 文件间依赖链：`原始数据dataset.csv →(01) data/signals.csv →(02, 需 analysis/复核明细.csv) data/final_all.csv →(03) data/final_all.xlsx`。
