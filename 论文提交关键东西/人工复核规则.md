# 人工复核规则与约定

> 本文件记录复核过程中确立的所有判定规则，确保复核标准一致、可追溯。

---

## 一、复核结果编码

| 编码 | 含义 | 适用场景 |
|------|------|---------|
| **valid1** | 基础有效 | 只答了一道开放题，或回答稍短但切题 |
| **valid2** | 严格有效 | 两题都答了，或一题但内容完整充实 |
| **invalid** | 无效 | 数据不可用，受访者乱答 |
| **unsure** | 不确定 | 边缘案例，标记后讨论 |

**核心区分**：
- **valid1** = 只答了一道开放题，内容基本切题，数据可用但不完美
- **valid2** = 两道开放题都认真作答，或一题但内容非常充实，数据质量最高
- 两者在最终分析中都算有效数据，但 valid2 是质量更高的子集

---

## 二、人工判定规则

### 2.1 两题都答 → 直接判定为 valid2

若受访者同时回答了 **BENEFIT_OPEN** 和 **TRUST_OPEN** 两道开放题（各 ≥3 字符），则直接判定为 **valid2**。

**逻辑**：愿意花时间回答两道开放题的受访者，数据质量可靠。

### 2.2 一票无效（第一轮已完成）

以下两类情况在第一轮筛查中已标记为无效，不进入复核队列：
- 全量表缺失（所有封闭题为空）
- 开放题纯乱码（字符熵 < 2.75 或符号占比 > 0.5 或数字占比 > 0.8）

## 三、longstring_exceed 判定

### 3.1 分类标准

| 子类 | 条件 | 判定倾向 |
|------|------|---------|
| **A-有效倾向** | 连续同选 32-34 且开放题有内容 | valid1 |
| **B-需判断(中等)** | 连续同选 35-59 且开放题有内容 | 逐条看开放题质量 |
| **C-需判断(极端)** | 连续同选 ≥60 且开放题有内容内容 | 严格判定 |
| **D-无效倾向** | 两题都空，或 ≥60 且开放题无内容 | invalid |

### 3.2 审查标准

#### A-有效倾向 → valid1
连续同选刚过阈值（32-34），开放题写了内容 → 只答一道，标 valid1。

#### B-需判断(中等) → 逐条审查
- 开放题内容合理、切题 → valid1（只答一道）
- 开放题为非实质性回答（"我不知道"、"没什么"、"没把握"、"好的"、"无"） → **invalid**
- 开放题乱码/答非所问 → invalid

#### C-需判断(极端) → 严格审查
连续同选 ≥60（几乎全选同一选项），且只答了一道开放题。标准：
- 开放题 ≥15 字且内容切题 → valid1
- 开放题 <15 字或语义模糊 → invalid
- 开放题乱码/答非所问 → invalid

#### D-无效倾向 → invalid
两题都空，或 ≥60 同选且开放题无内容 → 直接标 invalid。

## 四、VERIFY（IDN/PRT 注意力异常）

- 转跳原因：翻译/文化差异导致的系统性假异常，人工排查后确认非受访者问题
- 审查员只看开放题翻译
- 两题都答 → valid2
- 只答一题 → 看内容质量判断（valid1 或 invalid）

---

## 五、odd_even_low 审查

奇偶一致性非常低 = 反向题自相矛盾，通常是受访者未仔细读题。

### 审查标准
- 含 -99 或乱码 → invalid
- 开放题 0-5 字 → invalid
- 开放题 6-15 字，内容敷衍（"我不知道"、"不知道"、"很好"） → invalid
- 开放题 6-15 字，内容切题 → valid1（只答一道）
- 开放题 16+ 字 → valid1（只答一道）
- 两题都答 → valid2

## 六、mahalanobis_outlier 审查

马氏距离衡量答题模式与**本国常模**的偏离度（按国家分组计算，每个国家有自己的阈值）。触发可能有两种原因：
- 受访者的科学态度确实与众不同 → 有效
- 受访者在随机作答 → 无效

**按国家分组的原因**：不同国家在科学态度量表上存在系统性差异，整体计算会导致"在中国正常但在巴西异常"的误报。

### 审查标准

#### 短回答（<20 字）
- 含 -99/./符号 → invalid
- "Good""Idk""不知道"等敷衍回答 → invalid
- 短但切题（"所有人""人类""他的研究"） → valid1
- 拿不准 → unsure

#### 中长回答（20-50 字）
- 内容合理、切题 → valid1
- 内容前言不搭后语 → invalid

#### 长回答（>50 字）
- 内容合理 → valid1
- 内容异常 → 按实际情况判断

---

## 七、总体原则

1. **只标记，不删除**：所有数据在物理层面保留
2. **开放题是最终判据**：封闭题信号仅为辅助，开放题认真作答 = 数据可用
3. **区分 valid1/valid2**：复核结果列统一写 valid1（基础有效）/ valid2（严格有效）/ invalid（无效）/ unsure（不确定）
4. **可追溯**：每个决策都记录在 final_decision 列，可追溯到原始数据
