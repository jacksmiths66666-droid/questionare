## 数据清洗一览

| 指标 | 数量 |
|------|:----:|
| 原始数据 | 71,922 条 × 68 国 |
| 未触发信号（NORMAL） | 69,936 条 |
| 触发 1 个信号（MEDIUM） | 1,718 条（入队 1,323 条） |
| 触发 ≥2 个信号（HIGH） | 9 条（入队 6 条） |
| IDN/PRT 降级（VERIFY） | 259 条（入队 223 条） |
| 一票无效（全表缺失/乱码） | 13,816 条 |
| **人工复核入队** | **1,552 条** |
| 复核后有效（valid1 + valid2） | 1,110 条 |
| 复核后无效（invalid） | 442 条 |
| **分析就绪数据集** | **71,480 条（normal + valid1 + valid2）** |
| 标记无效 | 442 条（0.6%） |

> 注：复核过程中 9 条边界案例经采集全部证据（选择题作答模式 + 信号原始值 + 开放题内容）后二次确认，最终归入有效或无效，不保留不确定类别。

## 复核结果编码

- **valid1** = 基础有效（只答一道开放题，内容基本切题）
- **valid2** = 严格有效（两道开放题都认真作答）
- **invalid** = 无效
