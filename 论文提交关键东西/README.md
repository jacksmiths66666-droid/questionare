## 数据清洗一览

### 第一阶段：自动化筛查

| 指标 | 数量 | 说明 |
|------|:----:|------|
| 原始数据 | 71,922 条 × 68 国 | |
| **未触发任何信号（NORMAL）** | **69,936 条** | **未触发信号，为有效，不进复核** |
| 触发 1 个信号（MEDIUM） | 1,718 条 | 入队 1,323 条（其余被一票无效拦截） |
| 触发 ≥2 个信号（HIGH） | 9 条 | 入队 6 条（其余被一票无效拦截） |
| IDN/PRT 降级（VERIFY） | 259 条 | 入队 223 条（翻译假异常，不计信号） |
| 一票无效（全表缺失 / 开放题乱码） | 13,816 条 | 跳过复核，数据仍保留 |

### 第二阶段：人工复核（入队 1,552 条）

| 判定 | 数量 | 占比 |

> 注：9 条边界案例经采集全部证据（选择题作答模式 + 信号原始值 + 开放题内容）后二次确认，最终归入有效或无效，不保留不确定类别。

## 复核结果编码

- **valid1** = 基础有效（只答一道开放题，内容基本切题）
- **valid2** = 严格有效（两道开放题都认真作答）
- **invalid** = 无效
