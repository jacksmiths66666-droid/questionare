## 最终结果一览

### 第一阶段：信号筛选

| 指标 | 数量 |
|------|:----:|
| 原始数据 | 2,159（CATI 1,856 / CAWI 294 / 双通道 9） |
| 跳题一票否决（VETO） | 40（R1=3 + R2=37）→ 直接剔除 |
| 行为信号分层（通道一） | |
| 无信号（NORMAL） | 1,527 |
| 触发 1 个信号（MEDIUM） | 538 |
| 触发 ≥2 个信号（HIGH） | 54 |

### 第二阶段：分层复核（队列 592 条）

| 层级 | 有效 | 无效 | 有效率 |
|:----|:----:|:----:|:------:|
| HIGH | 23 | 31 | 42.6% |
| MEDIUM | 201 | 337 | 37.4% |

复核机制：三维度评分（A 开放题投入度 / B 作答形态 / C 过程背景，0–6 分）+ 门槛（A≥2 无条件剔除 363 行 + 总分 3–6 剔除 5 行）；详见 `docs/review_rules_full.md`。

信度复评：分层随机 20% 抽样 119 条，第一/第二编码员独立判定 → **119/119 一致，Cohen's κ = 1.000**（`analysis/信度检验_抽样119.csv`）

### 最终数据

| 判定 | 数量 | 占比 |
|:-----|:----:|:----:|
| **有效（valid）** | **1,751** | **81.10%** |
| 无效（invalid） | 408 | 18.90% |
| **合计** | **2,159** | **100%** |

剔除构成：跳题 40 + 复核 368（HIGH 31 + MEDIUM 337）

## 判定编码

- **valid** = 有效（NORMAL 直接判定 + 复核通过 224）
- **invalid** = 无效（VETO 跳题 40 + 复核未通过 368）
- `_source` 列：queue（复核判定）/ nonsignal（无信号基线）/ veto（跳题一票否决）
