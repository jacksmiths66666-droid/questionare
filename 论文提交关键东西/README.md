# TISP 数据质量筛查（最终版）

## 内容说明

### 方法文档

| 文件 | 说明 |
|------|------|
| `docs/review_rules_full.md` | **筛选与审核规则全流程**（行为信号分层 + 一票否决，论文方法论核心） |
| `docs/DATA_CLEANING_REPORT.md` | 数据清洗报告（流程、规则收紧记录、乱码检测修正） |
| `docs/FLOWCHART.md` | **全流程流程图**（阶段 → 动作 → 产出文件一一对应） |

### 数据文件（核心交付）

| 文件 | 说明 |
|------|------|
| `data/final_all.csv` | **最终数据集**（71,922 行 × 155 列，含 final_decision） |
| `data/final_all.xlsx` | 最终数据集彩色版（关键列条件着色，便于核查） |
| `data/review_queue.csv` | 审核队列（17,009 行，含逐行判定依据 reason） |
| `data/summary.csv` | 最终数字汇总 |

### 可复现脚本

| 文件 | 说明 |
|------|------|
| `脚本/01_screen.py` | 信号筛选（行为信号分层 + 一票否决） |
| `脚本/02_build_final.py` | 最终数据集生成（队列判定 + 乱码检测内联） |
| `脚本/03_build_xlsx.py` | 彩色 xlsx 生成 |

> 分层内容审核（HIGH / VERIFY / MEDIUM）按 `docs/review_rules_full.md` 的判定标准逐条执行。

### 目录结构与复现

```
论文提交关键东西/
├── 原始数据dataset.csv    ← 原始数据（71,922 × 126）
├── data/                  ← 最终交付数据（直接使用）
├── outputs/               ← 脚本复现输出（预置 signals.csv）
├── docs/                  ← 方法文档
└── 脚本/                  ← 复现脚本（相对路径，基于本目录定位）
```

复现步骤（在包内执行，路径全部相对本包）：

```bash
python 脚本/01_screen.py          # 信号筛选 → outputs/signals.csv
python 脚本/02_build_final.py     # 最终数据集 → outputs/final_all.csv
python 脚本/03_build_xlsx.py      # 彩色版 → outputs/final_all.xlsx
```

`data/` 为最终交付数据；复现产物由脚本生成于 `outputs/`（仅预置 signals.csv），两者应一致。

## 判定编码

- **valid** = 有效（非队列行乱码检测通过直接判定 + 各层复核通过）
- **invalid** = 无效（乱码 77 行 / 各层复核未通过）
- `_source` 列：queue（复核判定）/ nonsignal（非队列基线）/ gibberish（乱码判定）
