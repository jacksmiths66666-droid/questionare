## 五、阈值合理性说明

| 指标 | 阈值 | 依据 |
|---|---|---|
| DUR 低 | 5.5 min | P1分位；29道题不可能在5分钟内认真答完 |
| DUR 高 | 34.5 min | P99分位；排除通话中断等异常 |
| 马氏距离 | D² > 11.0 | P95分位；远离正常作答云的尾部 |
| Longstring | ≥ 7 | P97分位；10题中连续7题相同概率极低 |
| DK/NA | ≥ 5 | P95分位；55题中仅4%以内的人有5个以上"不知道" |
