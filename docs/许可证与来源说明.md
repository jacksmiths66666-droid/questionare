官方记录说明该仓储提供英文与西班牙文问卷，并提供原始数据的 CSV 和 DTA 格式。本目录仅保留两份官方 CSV，未转换或改写；DTA 因与 CSV 为同一官方数据的格式变体而未重复纳入。

官方记录 JSON 原样留档于同目录 `01_Figshare官方记录.json`，其中含文件名、下载地址、MD5、许可、作者及发布元数据。
