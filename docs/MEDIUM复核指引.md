# MEDIUM 板块人工复核指引

## 概况

| 触发原因 | 数量 | 说明 |
|---------|------|------|
| longstring_exceed | 538 | 连续≥32题同选（有14条两题开放题都空白） |
| odd_even_low | 478 | 反向题对高度不一致（全部有开放题） |
| mahalanobis_outlier | 303 | 答题模式偏离国家常模（全部有开放题） |
| attention_fail | 4 | 注意力题答错（全部有开放题） |
| **合计** | **1,323** | |

## 判定标准

```
valid   ✅   = 开放题回答认真、切题，信号为假阳性
invalid ❌   = 开放题乱答/答非所问/明显随意
unsure  ❓   = 边缘案例，或信号极强但开放题看不太清楚的
```

## 各类型判断要点

### ① longstring_exceed（538条）
- 连续选同一选项，通常为省时间乱点
- **先看开放题是否认真作答**
  - 有开放题且认真 → 可能受访者存在答题惯性但并未乱答
  - 开放题空白或极短(1-2词) → 较可能是无效
- 重点看信号极端值：连续33同选还是连续71同选

### ② odd_even_low（478条）
- 奇偶一致性非常低=反向题自相矛盾
- 通常受访者根本没有读题
- **先看开放题**
  - 开放题认真回答 → 可能只是理解偏差
  - 开放题也前言不搭后语 → 无效

### ③ mahalanobis_outlier（303条）
- 多维离群值，可能只是该受访者观点确实与众不同
- **强烈依赖开放题判断**
  - 开放题认真且内容合理 → valid（此人确有其独特观点）
  - 开放题随便填/奇怪 → invalid

### ④ attention_fail（4条）
- 与 VERIFY 的不同：非 IDN/PRT，是真答错
- 开放题认真程度决定一切

## 效率技巧

1. 先看**开放题翻译**，翻译明显认真→直接标 valid
2. 翻译为空或极短→切回原文确认是否原文有内容
3. 12-13秒1条，预计总耗时约4-5小时
4. 按触发原因分批处理，保持思维连贯

## 建议顺序

longstring_exceed(538) → odd_even_low(478) → mahalanobis_outlier(303) → attention_fail(4)
